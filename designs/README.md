## Design authority

1. Hackney Design System: https://design-system.hackney.gov.uk/ — primary for council headers, typography, forms, buttons, links and accessibility patterns.
2. Material Design 3: https://m3.material.io/ — secondary guidance for adaptive layouts, surfaces, component hierarchy and state changes; do not overwrite Hackney-specific styles with default Material.
